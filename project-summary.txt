1. PROJECT OVERVIEW
--------------------------------------------------------------------------------
SARVAM-X is a full-stack, split-stack application composed of two primary
interdisciplinary modules:

  A. SARVAM Cognitive Suite (Personalized AI Learning Portal):
     - Calculates virtual learning proficiency metrics ("Digital Twin").
     - Predicts exam performance using local Machine Learning (Scikit-Learn).
     - Explains score predictions using mathematical SHAP values (XAI).
     - Models interactive study scenarios ("What-If Simulator").
     - Parses Python code for syntax structure & vulnerabilities ("AST Debugger").
     - Adaptively guides the user with a webcam facial expression reader
       ("face-api.js" Emotion AI) and streaming LLM guidance (NVIDIA NIM Llama 3.1).

  B. TRINETRA Secure Sentinel (AI Cybersecurity Portal):
     - Predicts misinformation probability in text using Natural Language
       Processing ("NLP Fake News Classifier").
     - Explains positive/negative lexical framing.
     - Scans source code for vulnerabilities (SQL injection, hardcoded secrets,
       buffer overflows, command injection).
     - Visualizes risk registers and security threat maps.

3. HOW THE COMPONENTS INTERCONNECT (DATA FLOW)
--------------------------------------------------------------------------------

[ USER SIGN IN FLOW ]
  User enters credentials in AuthView.tsx ──> Fetched by api.ts ──> POSTs to Flask
  (/api/auth/login) ──> verifies with database.py ──> Returns user ID, name, email.

[ DIGITAL TWIN PREDICT FLOW ]
  SarvamSuite.tsx mounts ──> Calls api.getDashboard(userId) ──> database.py queries
  sessions and topic scores ──> twin_model.py trains local estimator ──>
  explainer.py calculates influence weight ──> Returns KPIs, scores, SHAP values 
  ──> Rendered by Chart.js in the browser.

[ COGNITIVE AI MENTOR FLOW ]
  Webcam turns on in MentorPanel.tsx ──> face-api.js evaluates face coordinates
  ──> classifies emotion (neutral, happy, etc.) ──> User speaks/chats ──> Chat
  POSTed to Flask (/api/chat) with emotion ──> Flask builds prompt injecting
  emotion context ──> Streams tokens directly from NVIDIA Llama 3.1 ──> UI streams
  text to screen.

4. THE VERCEL SERVERLESS MAGIC
--------------------------------------------------------------------------------
Vercel is traditionally for static pages, but we configured it to run the entire
Flask API dynamically!

- ROUTING RULES (vercel.json):
  All requests beginning with "/api" are intercepted by Vercel and sent to
  "backend/app.py" under the "@vercel/python" runtime. All other requests are
  served instantly as static precompiled HTML/JS from the Vite React build.

- DYNAMIC COMPILER (vite.config.ts):
  If the bundler detects it is running inside the Vercel build environment, it
  compiles React into "/dist" (where Vercel expects it). If it runs locally on
  your computer, it compiles into "../frontend" (where Flask expects it).

- EPHEMERAL SQLITE ENGINE (database.py):
  The local filesystem of Vercel containers is read-only. We check if the Vercel
  flag is active; if it is, we direct SQLite to save the DB file to "/tmp/sarvam.db"
  (the only writable directory in serverless environments) and auto-initialize it
  on cold starts.

5. RUNNING THE PROJECT LOCALLY
--------------------------------------------------------------------------------

A. Run the Python Backend & Dev Server (Flask serves static files):
   1. Open terminal: `cd backend`
   2. Start virtual env: `.venv\Scripts\Activate.ps1` (or source .venv/bin/activate)
   3. Start backend: `python app.py`
   4. Open `http://localhost:5000` in your web browser.

B. Run React Frontend Developer Mode (Hot-Reloading):
   1. Open a new terminal: `cd client`
   2. Run: `npm run dev`
   3. Open the dev URL (usually `http://localhost:5173`) in your browser.
      (In dev mode, Vite automatically proxies API calls to port 5000!)

C. Compile changes for Production:
   1. `cd client`
   2. `npm run build`
      (This compiles your frontend and moves it to `/frontend` so the Flask
      app serves the fresh updates at port 5000 instantly!)
